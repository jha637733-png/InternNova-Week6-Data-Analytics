# InternNova Week 6 – Final Data Analytics Project

## Project Overview
This project demonstrates data analytics skills using Python, Excel, Power BI, and GitHub. It focuses on retail sales data analysis, exploratory data analysis (EDA), data visualization, and business insights.

## Tools and Technologies
- Python 3.11
- Pandas
- Matplotlib
- Seaborn
- Excel
- Power BI
- Git and GitHub
## Project Structure
- `Dataset/` – Original retail sales dataset
- `PowerBI/` – Power BI report file
- `Visualizations/` – EDA charts and cleaned dataset
- `retail_sales_analysis.py` – Python analysis script

## Analysis Performed
- Dataset inspection and descriptive statistics
- Missing-value and duplicate-row checks
- Duplicate removal
- Numeric distributions and category counts
- Correlation heatmap and outlier overview
- Export of the cleaned dataset
## How to Run
1. Install Python.
2. Install packages: pandas, openpyxl, matplotlib, seaborn.
3. Place the Excel dataset inside the Dataset folder.
4. Run the Python script: `python retail_sales_analysis.py`
